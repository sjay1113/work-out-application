# PT 운동 노트

트레이너가 손으로 적어 준 운동 루틴(OT ~ 11/9, 21회)을 휴대폰에서 보기 쉽게 만든 웹앱입니다.

- **홈**: 오늘 할 부위(어깨 → 하체 → 가슴 → 등 순서)와 루틴 카드, 부위별 최근 날짜, 지금까지 기록 요약.
- **운동 화면**: 세트마다 지난번 기록 · 무게 · 횟수 · 완료 체크. 체크하면 휴식 타이머(1분 30초, ±15초)가 자동으로 시작되고, 운동하는 동안 화면이 꺼지지 않습니다. 끝나면 운동 시간 · 세트 · 총 볼륨 요약.
- **루틴 만들기** (홈의 "루틴 바꾸기"): 운동 개수(2~6개)와 부위를 고르면 맨 위에 AI 코치 추천(큰 근육·다관절 먼저 → 작은 근육 마무리)이 나오고, 부위별 운동 목록에서 직접 고를 수 있습니다. 고른 운동과 잘 맞는 운동에는 "같이 하면 좋아요"가 이유와 함께 표시되고, 세트·무게·횟수를 조절한 뒤 큰 근육 순서로 시작합니다.
- **운동 중 바꾸기**: 세트별 무게·횟수 수정(아래 세트에도 같이 반영), 세트 추가/빼기, 운동 바꾸기·추가·빼기.
- **기록**: 월별 운동 목록. 누르면 그날 루틴을 보고 바로 시작할 수 있습니다.
- **운동법**: 운동별 쌤 메모, 움직이는 자세 그림(시작 자세 → 끝 자세를 반복, 멈춤 가능, 쌤 원본도 볼 수 있음), 무게 변화 그래프.

`index.html` 하나로 동작하며, 홈 화면에 추가하면 앱처럼 열립니다.
루틴 데이터는 `index.html` 안의 `const S=[...]`, 운동 분류·추천 순서·짝꿍 운동은 `META` · `GROUPS` · `PAIRS`, 자세 그림은 `ILLU`, 원본 손그림 연결은 `DRAW`에 있습니다.
## 기록 저장
- "운동 끝내기"를 누르면 완료한 세트(무게·횟수)가 **기록**에 쌓이고, 다음 운동 때 "지난번" 칸과 무게 그래프에 반영됩니다.
- 이 주소(깃허브)에서 열면 로그인 없이 **자동 익명 계정**으로 기록이 Supabase의 `workouts` 테이블에 저장되어 다른 기기에서도 보입니다(본인 기록만 읽고 쓰는 보안 규칙 적용). DBeaver로 같은 DB에 접속해 `workouts` / `workout_sets` 를 볼 수 있습니다.
- Supabase에서 익명 로그인(Allow anonymous sign-ins)이 꺼져 있으면 **그 휴대폰 브라우저**에 저장되고, 켜지면 다음에 열 때 서버로 옮겨집니다.
- claude.ai 링크로 열면 본인 계정의 개인 공간에 저장되어 다른 기기에서도 보이고, 다른 사람(공유한 사람 포함)은 볼 수 없습니다.
